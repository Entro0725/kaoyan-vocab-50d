# 考研词汇 · 50 天冲刺（网页版）

访问：https://entro0725.github.io/kaoyan-vocab-50d/

本项目现在**只维护网页版**；不再提供 Android APK，也不再打包机械式离线发音。

- **4,924 条词汇**，保留原考频降序与精简中文释义。
- 默认目标考频 ≥4：**2,393 词**；冲刺 ≥3：**2,873 词**；扩展 ≥2：**3,642 词**。
- 支持自定义每日复习目标与每轮复习量，例如 100 次或 120 次。
- 答错后的复习间隔可选 5 分钟、10 分钟或自定义。
- 支持自由复习、难词收藏、学习统计以及 JSON 进度导入导出。
- 点击喇叭使用**浏览器的 Web Speech API** 朗读英文单词。实际语音质量、口音和可用性由浏览器及设备决定；网站不附带离线发音包。
- 学习进度保存在浏览器本地，未提供跨设备自动同步。存储键保持不变，原网页版的进度可继续使用。

## 测试与部署

纯静态网页，无 Android SDK、Gradle 或第三方运行依赖。

```bash
npm test
npm run build
```

运行 `npm run build` 会先检查词表与复习逻辑，再**清空旧 dist 目录**并仅输出 `dist/index.html`，确保 APK 和音频文件不会继续被部署。

推送到 `main` 后，GitHub Actions 自动测试、构建并部署到 GitHub Pages。

## 词频说明

考频包含原始资料的估算值，不应将所有数值视为真实历年真题出现次数。
