# 考研词汇 · 50 天冲刺

适合手机和电脑的轻量英语词汇记忆网页 App。使用用户最终版《词汇乱序·释义精简版》：**4,924 条词汇**，保留原始考频排列与简洁中文释义。

## 使用

访问部署地址：https://entro0725.github.io/kaoyan-vocab-50d/

- 默认考频 ≥4：**2,393 词**（优先完成）。
- 冲刺考频 ≥3：**2,873 词**；扩展考频 ≥2：**3,642 词**。
- 42 天学习新词、8 天集中复习；先回忆中文意思，再揭示答案，按「不会、模糊、记得、熟练」评分安排复习。
- 提供浏览器英美语音朗读、难词收藏、助记提示、词表搜索、进度统计、JSON 导入导出。
- 数据仅保存在当前浏览器本地，不会自动跨设备同步。建议定期导出学习记录。
- 词频含原资料的估算值，不能全部当作真实真题出现次数。

## 开发与部署

本仓库采用**单文件离线 HTML App**，将必要的 CSS、JS 和 4,924 条词汇直接打包进 `index.html`，无需服务器、数据库或外部依赖。

```bash
npm test
npm run build
```

`npm test` 核对完整词表、词频降序、筛选数量与发音/复习能力；`npm run build` 检查后输出 `dist/index.html`。

`.github/workflows/deploy.yml` 在推送到 `main` 后自动运行测试和构建，再尝试部署 GitHub Pages。首次需要在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。

## 说明

- App 可在桌面/手机浏览器使用。由于已将词表内嵌，打开后不依赖网络读取词库；系统语音的可用性由浏览器和设备决定。
- “已掌握”的判断基于多次主动回忆和间隔复习，并不保证考试得分。
- 本项目使用用户提供的词汇文本。公开仓库会公开词表，发布者应确认相关内容的使用和再分发权利。
